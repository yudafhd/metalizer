Panduan Penggunaan Metalizer

Aplikasi pembuatan metadata batch gambar untuk Adobe Stock.
1

Instalasi

  1. Download file installer Metalizer_0.2.0_x64-setup.exe (Windows) atau Metalizer_0.2.0_aarch64.dmg (macOS).
  2. Buka file installer dan ikuti instruksi hingga selesai.
  3. Buka aplikasi Metalizer.
Jika muncul notifikasi "Windows protected your PC", klik More info lalu pilih Run anyway.
2

Aktivasi Lisensi

Saat aplikasi pertama kali dibuka, masukkan data lisensi yang Anda terima saat pembelian:

  1. Masukkan Email yang digunakan saat membeli.
  2. Masukkan Kode Lisensi (kode panjang yang diawali SLC1.).
  3. Klik tombol Aktivasi.
Catatan: Lisensi terikat ke 1 perangkat (PC/Laptop). Pastikan email sesuai dengan data saat transaksi.
3

Setup Gemini API Key

Metalizer memerlukan Gemini API Key dari Google (tersedia kuota gratis).

  1. Buka Google AI Studio (aistudio.google.com/app/apikey).
  2. Login dengan akun Google, lalu klik Create API key.
  3. Salin API Key yang dihasilkan.
  4. Di aplikasi Metalizer, klik ikon Settings (kanan atas), paste API key pada kolom yang tersedia, lalu simpan.
Mode Metadata Deskripsi
Strict (Ketat) Keyword hanya berdasarkan objek nyata yang terlihat.
Balanced (Seimbang) Campuran objek langsung dan konsep relevan (default yang disarankan).
Discovery (Eksplorasi) Menjangkau konsep visual lebih luas dan kata kunci turunan.
4

Impor Gambar

  1. Tarik file gambar atau folder langsung ke dalam jendela aplikasi, atau klik tombol Import Folder.
  2. Format yang didukung: .jpg, .jpeg, .png, .webp, dan .svg.
  3. File asli di komputer tidak akan diubah atau ditimpa.
5

Generate Metadata

  1. Klik tombol Generate Metadata.
  2. Aplikasi akan memproses gambar secara batch (membuat contact sheet hemat token).
  3. Tunggu hingga progress bar mencapai 100%.
6

Review & Edit

  • Inspector: Klik gambar untuk melihat dan mengedit Title, Kategori, atau Keywords.
  • Warnings: Sistem akan menandai kata berulang (duplikat) atau merk/brand yang berisiko ditolak oleh microstock.
  • Bulk Edit: Pilih beberapa gambar sekaligus untuk mengganti kategori atau menambah keyword secara bersamaan.
7

Ekspor CSV

  1. Klik tombol Export CSV.
  2. Pilih lokasi penyimpanan di komputer Anda.
  3. File CSV akan tersimpan dengan format standar UTF-8 Adobe Stock:
Filename,Title,Keywords,Category
IMG_001.jpg,"Modern coffee shop interior with wooden table","coffee shop, cafe, interior, table, espresso, lifestyle",10
8

Upload ke Adobe Stock

  1. Login ke Adobe Stock Contributor.
  2. Upload file-file gambar Anda.
  3. Di menu Uploaded Files, klik Upload CSV dan pilih file CSV yang diekspor dari Metalizer.
  4. Metadata akan otomatis terisi sesuai nama file. Periksa lalu klik Submit.

Solusi Kendala (Troubleshooting)

1. Error 429 / Rate Limit (Too Many Requests)

Kuota per menit free-tier Gemini tercapai. Buka menu Settings, atur Concurrency ke 1 dan Batch Size ke 4 atau 6. Tunggu 1 menit lalu lanjutkan.

2. Error "Invalid API Key"

Pastikan API key disalin lengkap tanpa spasi tambahan di awal/akhir pada menu Settings.

3. Ganti Perangkat / Laptop

Lisensi terikat pada hardware ID perangkat. Jika ingin memindahkan instalasi ke laptop baru, hubungi kontak kami untuk reset aktivasi lisensi.
